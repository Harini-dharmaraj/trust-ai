# TrustCircle AI

A production-style MERN starter for a community finance management platform with AI-powered insights, transparent contributions, and role-based workflows.

## Quick start

1. Install dependencies:
   ```bash
   npm run install:all
   ```
2. Start the app:
   ```bash
   npm run dev
   ```
3. Open the frontend at http://localhost:5173 and the API at http://localhost:5000.

## Structure

- client: React + Vite + Tailwind frontend
- server: Express + MongoDB-ready backend
